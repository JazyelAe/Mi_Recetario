# Mi Recetario

Aplicación web sencilla de recetas de cocina casera, con filtros por categoría, buscador de ingredientes y formulario de sugerencias.

Proyecto académico — Universidad Tecnológica de Puebla (Aplicaciones Web Progresivas).

## Tecnologías
HTML5, CSS3 y JavaScript (sin frameworks ni backend). Todo se ejecuta en el navegador.

## Estructura
```
index.html
css/styles.css
js/app.js
```

## Cómo usarla
Abre `index.html` en el navegador, o publícala con GitHub Pages
(Settings → Pages → Branch: main → carpeta / (root)).
